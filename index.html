      Réglages

      Le prénom affiché en haut de l'accueil, sous « Bonjour ». Il est gardé dans la mémoire de cet appareil : à changer sur chaque appareil (PC, iPhone).

      Exporter crée un fichier avec toutes tes fiches (recettes, cocktails, photos) et tes notes. Importer remplace toutes les fiches par celles d'un fichier exporté par Toque&Tonic (les sauvegardes de Wodo restent à Wodo).

      Adresse du relais qui permet d'importer une recette ou un cocktail depuis un lien (le même relais que Wodo ; mode d'emploi dans le projet Wodo : relais/LISEZMOI-RELAIS.md). Elle est gardée uniquement dans la mémoire de cet appareil : jamais envoyée sur GitHub, jamais mise dans les exports.

      Clé API Gemini, pour créer une recette ou un cocktail à partir de photos et de texte (à créer sur aistudio.google.com, « Get API key »). Elle est gardée uniquement dans la mémoire de cet appareil : jamais envoyée sur GitHub, jamais mise dans les exports, jamais réaffichée.
